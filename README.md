# 🚀 Programming Roadmap

Repositorio donde documento mi proceso de aprendizaje en programación e Ingeniería de Software.

Aquí encontrarás mis apuntes, ejercicios, mini proyectos y recursos organizados siguiendo una ruta de estudio estructurada. El objetivo no es únicamente almacenar código, sino registrar mi evolución como desarrollador desde los fundamentos hasta áreas más avanzadas.

---

## 🎯 Objetivo

Construir una base de conocimiento personal mientras desarrollo habilidades como Software Engineer.

Este repositorio documenta:

- 📚 Apuntes técnicos
- 💻 Ejercicios prácticos
- 🚀 Mini proyectos
- 📝 Reflexiones y aprendizajes
- 📈 Mi progreso durante la ruta de estudio

---

## 🗺️ Ruta de aprendizaje

La ruta de estudio sigue el siguiente orden:

1. Cómo estudiar programación
2. Terminal
3. Git
4. Lógica de programación
5. Python
6. Java
7. HTML
8. CSS
9. JavaScript
10. SQL
11. Backend
