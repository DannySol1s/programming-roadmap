# Untracked (Git)

**Categoría:** Git / Control de versiones

## Definición
Un archivo "untracked" (sin rastrear) es uno que existe en el directorio de trabajo pero que git nunca ha visto — no forma parte de ningún commit ni fue agregado con `git add`. Git lo ignora hasta que decides incluirlo explícitamente.

## Ejemplo
Los archivos de `glosario/` aparecieron como "Untracked files" en `git status` hasta el primer `git add` — es la marca "U" que se ve en el explorador de VS Code (Source Control) junto a cada archivo nuevo.
