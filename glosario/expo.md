## Definición

Expo es un conjunto de herramientas y servicios que simplifica el desarrollo de aplicaciones móviles con React Native. Incluye APIs listas para usar, un entorno de desarrollo y servicios para compilar, publicar y actualizar aplicaciones para Android e iOS.

Expo no reemplaza a React Native: se construye sobre él y agrega una experiencia de desarrollo más sencilla. Para probar una aplicación rápidamente se puede usar **Expo Go**; para generar builds personalizadas y gestionar el proceso de publicación se pueden utilizar los servicios de **EAS (Expo Application Services)**.

## Ejemplo

Crear y ejecutar una aplicación de Expo:

```bash
npx create-expo-app@latest mi-app
cd mi-app
npx expo start
```

Después, el código QR mostrado por el servidor de desarrollo puede abrirse con Expo Go en un dispositivo móvil conectado a la misma red.
