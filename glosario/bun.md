# Bun

**Categoría:** Backend / Arquitectura
**Visto en:** programming-roadmap

## Definición

Bun es un runtime de JavaScript y TypeScript diseñado para ejecutar aplicaciones del lado del servidor. Incluye herramientas integradas como gestor de paquetes, bundler y ejecutor de pruebas, con el objetivo de reducir dependencias y mejorar el rendimiento del desarrollo.

Es compatible con gran parte del ecosistema de Node.js, aunque se debe verificar la compatibilidad de las dependencias antes de migrar un proyecto.

## Ejemplo

Ejecutar una API desarrollada con Hono:

````bash
bun install
bun run src/index.ts
